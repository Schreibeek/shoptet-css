# shoptet-css

Vlastní CSS pro e-shopy na Shoptetu, běží přes GitHub Pages (https://schreibeek.github.io/shoptet-css/...).

- lederer.css - lukaslederer.cz, načítá se v záhlaví Shoptetu (?v= v odkazu zvednout po každé změně).
- lederer-test.css - testovací vzhled lukaslederer.cz podle design systému v2. Načítá se jen s ?lltest=1 (přepínač je v shoptet-js/lederer.js), vždy čerstvý, ?v= se neřeší.
