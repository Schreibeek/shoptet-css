# shoptet-css

Vlastní CSS pro e-shopy na Shoptetu, běží přes GitHub Pages (https://schreibeek.github.io/shoptet-css/...).

- lederer.css - lukaslederer.cz, načítá se v záhlaví Shoptetu (?v= v odkazu zvednout po každé změně). Nahoře obecné úpravy šablony a kampaní, pod nimi vzhled podle design systému v2 (ostrý od 3. 11. 2026, dřív testovací lederer-test.css), pravidla s předponou html:root.
- backup/puvodni-vzhled-2026-11-03/ - původní vzhled lukaslederer.cz před přepnutím (lederer.css a HTML kódy z administrace), postup obnovy je v README.md ve složce.
