# Původní vzhled lukaslederer.cz (do 3. 11. 2026)

Záloha vzhledu, který měli zákazníci před přepnutím na nový vzhled podle design systému v2. Už se nepoužívá.

- `lederer.css` - původní styly (načítaly se z `https://schreibeek.github.io/shoptet-css/lederer.css?v=1.50`).
- Repozitář shoptet-js, `backup/puvodni-vzhled-2026-11-03/lederer.js` - původní skripty (`lederer.js?v=1.28`), na začátku s přepínačem testovacího vzhledu `?lltest=1`.
- `html-kody-zahlavi.html` a `html-kody-zapati.html` - HTML kódy z administrace (Nastavení > HTML kódy) v den přepnutí, se skriptem testovacího vzhledu v záhlaví.

Obnova: tyto dva soubory vrátit do kořene repozitářů jako `lederer.css` a `lederer.js` a v administraci vrátit HTML kódy (nebo jen verze odkazů). Původní obsah bannerů v patičce je v `../paticka-bannery-2026-11-02.html`.
